BookNest 
O BookNest é um site desenvolvido para ajudar leitores a organizar suas leituras em um espaço pessoal. A proposta é oferecer uma experiência simples, com foco nos livros, sem as características de uma rede social.

Funcionalidades

Página inicial: apresentação do projeto e sugestões de leitura.

Biblioteca pessoal: organização dos livros por categorias e estágios de leitura.

Detalhes dos livros: informações sobre título, autor, gênero e sinopse.

Perfil: checagem de informações e gêneros literários preferidos.

Login: página de acesso à conta do usuário.

Tecnologias utilizadas
HTML5
CSS3
